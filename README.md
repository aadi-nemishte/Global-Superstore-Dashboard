# Global-Superstore-Dashboard
This project is an interactive business intelligence dashboard designed to analyze and visualize global retail sales data. It turns raw transactional data into clear, actionable insights to help track company performance, profitability, and customer behavior.
1. Project Title / Headline
🌍 Global Superstore Sales Performance Dashboard
An interactive and visually driven Power BI dashboard designed to analyze global sales performance, customer trends, profitability, and regional business insights across multiple categories and market segments.

2. Short Description / Purpose
The Global Superstore Dashboard is a professional Power BI report created to help users monitor and analyze worldwide retail sales data through interactive visualizations and KPI tracking.
The dashboard enables businesses, analysts, and decision-makers to explore sales trends, customer behavior, regional performance, product categories, and profitability insights in a clear and data-driven way.

3. Tech Stack
The dashboard was built using the following tools and technologies:
📊 Power BI Desktop – Main platform used for building interactive reports and visualizations.
📂 Power Query – Used for data cleaning, transformation, and preprocessing.
🧠 DAX (Data Analysis Expressions) – Used for creating calculated measures, KPIs, and dynamic calculations.
🔗 Data Modeling – Relationships between sales, customers, regions, and product categories enabled efficient filtering and aggregation.
🎨 Custom Visual Design – Gradient themes, KPI cards, slicers, maps, donut charts, and interactive buttons were used for modern dashboard styling.
📁 File Formats – .pbix/.pbit for development and .png for dashboard previews.
4. Data Source
Source: Global Superstore Dataset
The dataset contains worldwide retail sales transaction data including:
Order details
Sales and profit values
Customer information
Product categories and sub-categories
Quantity and discount details
Regional and state-wise sales data
Segment-based customer classification
The dataset is structured to support business intelligence analysis across multiple dimensions such as geography, category performance, and yearly sales trends.

5. Features / Highlights
• Business Problem
Large retail businesses generate massive amounts of sales data across different regions, categories, and customer segments. However, understanding:
Which regions generate the highest revenue
Which product categories are most profitable
How discounts affect profit
Which customer segments drive sales
Yearly sales growth trends can be difficult when using raw spreadsheets or traditional reports.

• Goal of the Dashboard
The main goal of this dashboard is to provide an interactive business intelligence solution that:
Tracks overall sales and profit performance
Identifies high-performing regions and product categories
Monitors customer and segment contributions
Visualizes sales growth trends over time
Supports strategic business decision-making through data insights
